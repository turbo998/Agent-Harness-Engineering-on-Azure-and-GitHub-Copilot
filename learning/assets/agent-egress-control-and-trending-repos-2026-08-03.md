# Agent 出站流量治理模式（2026-08-03）

## 出站控制模式

- 将网络出站控制与 agent 工具权限分开设计、配置和审计；工具获准调用不意味着所有外部目标都应放行。
- 先列出必需的 API、数据源和外部服务，再建立最小出站允许清单。
- 将网络控制、日志脱敏、身份授权作为独立的控制层；架构图应分别标出执行点和审计输出。
- POC 使用隔离测试环境，验证允许目标可达、未允许目标被拒绝、拒绝事件可审计；不要使用真实客户敏感数据。
