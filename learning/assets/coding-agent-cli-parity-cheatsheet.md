# 编码 Agent CLI 三栈配置对照与迁移验收模板

> **发布界定**：由历史研究材料提炼的迁移设计模板，不是当前功能支持矩阵。本次没有安装或运行 Codex、Claude Code、GitHub Copilot；不构成生产或合规保证。具体目录、字段和行为必须按目标产品、宿主及版本核验。

## 1. 能否共用一套配置？

**可复用的是团队规则与任务流程的主体，不是未经验证的整套运行配置。** `AGENTS.md`、`CLAUDE.md`、`SKILL.md` 等文件提供组织内容的思路，但宿主可能采用不同发现目录、覆盖顺序、字段、上下文角色和工具权限模型。相同文件名也不证明行为相同。

迁移时分三层：

| 层 | 尽量复用 | 必须适配/验证 |
|---|---|---|
| 内容 | 团队编码规范、任务步骤、验收标准 | 指令冲突、过时规则、上下文预算 |
| 发现与打包 | 技能主体、参考资料、模板布局 | 目录、manifest、frontmatter、注册与触发规则 |
| 执行与安全 | 威胁模型、测试案例 | 工具名、参数、沙箱、审批、网络、身份与审计 |

## 2. 按宿主分别填写的配置矩阵

不要仅填写“支持/不支持”；给出**版本＋官方出处＋最小复现结果**。没有验证的格子保留“待核实”。

| 检查项 | Codex | Claude Code | GitHub Copilot |
|---|---|---|---|
| 项目指令文件及发现顺序 | 待核实 | 待核实 | 待核实，注明IDE/CLI/云端形态 |
| 用户、项目、嵌套目录的优先级 | 待核实 | 待核实 | 待核实 |
| 技能目录与frontmatter字段 | 待核实 | 待核实 | 待核实 |
| 显式/隐式技能触发 | 待核实 | 待核实 | 待核实 |
| 子代理配置、上下文与权限继承 | 待核实 | 待核实 | 待核实 |
| hooks事件、输入输出和失败契约 | 待核实 | 待核实 | 待核实 |
| MCP传输、身份、审批和日志 | 待核实 | 待核实 | 待核实 |
| 插件manifest与依赖锁定 | 待核实 | 待核实 | 待核实 |
| 无人值守触发、执行位置和凭据 | 待核实 | 待核实 | 待核实 |
| 组织强制策略与个人可覆盖设置 | 待核实 | 待核实 | 待核实 |

社区转换器的目录映射属于适配层声明，不能写成厂商原生支持。插件格式能读取，也不等于其中的hook、命令、环境变量与权限行为兼容。

## 3. 可复用技能内容的目录示例

这是内容组织模板，不是所有宿主的强制schema：

```text
my-skill/
  SKILL.md       # 描述用途、触发条件、步骤、验收与失败处理
  references/    # 按需读取的资料及出处
  assets/        # 不含秘密的模板与样板
  scripts/       # 可选；必须独立审计依赖和执行权限
```

- 主体简洁，但不要为了省token删除关键安全约束。
- 描述说明什么时候使用、什么时候不使用。
- 明确输入、产出、可检查的完成标准和失败回退。
- 宿主扩展元数据与主体分开维护，不假定某个宿主只需要一份YAML文件。
- 每个宿主独立验证触发、加载、权限和实际结果；不要把社区自述视为本项目兼容性实证。

## 4. 安全迁移门禁

1. **指令边界**：外部资料、工具输出和第三方技能不得越权覆盖高优先级指令。
2. **权限边界**：文档约束不能替代文件、网络、身份与工具层的强制控制。
3. **审批绑定**：授权需绑定当前动作和参数；子代理、恢复会话和改写参数后重新评估。
4. **失败行为**：验证工具超时、非法输出、缺失凭据及取消任务，不能静默放行。
5. **可观测性**：记录工具调用、审批、版本与测试结果；日志和产物不含真实秘密。
6. **部署位置**：本地调度不等于数据不出机器，模型请求、遥测与远程工具需单独核验。
7. **云端差异**：目标租户、区域、网络和数据驻留没有验证之前，不承诺生产可用或合规。

## 5. Workshop 练习卡

**目标**：把一项小型代码检查流程迁移到两个编码Agent宿主，证明“复用内容＋适配运行配置”，而非宣称无差别运行。

**输入**：临时toy repo、相同规则、一个正常样例和两个负向样例；不使用客户代码与真实token。

**步骤**：
- 记录两个宿主的版本、指令发现配置与工具权限。
- 分别执行同一任务，收集实际加载的规则和工具调用。
- 构造规则冲突、缺失工具、禁止网络三个失败情形。
- 对比结果并记录必须适配的字段，不以模型声称读过文件作为证据。

**验收产物**：填好的矩阵、最小适配diff、测试结果、独立审查问题清单、未验证项。
