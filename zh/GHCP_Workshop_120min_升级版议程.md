# GitHub Copilot 客户技术工作坊 — 升级版议程（120 分钟）

## Workshop 主题
**GitHub Copilot：从 IDE 助手到 Agent 工作流 — AI-DLC · Harness Engineering · Multi-Agent 协作**

## 目标受众
客户技术团队、架构师、技术负责人、核心开发成员

## 120 分钟议程

| # | 环节 | 时长 | 内容 | 模式 |
|---|------|------|------|------|
| 1 | 开场与目标对齐 | 5 min | Workshop 目标、学习成果、今天会交付什么 | 讲解 |
| 2 | GHCP 核心操作与 IDE 路径 | 10 min | Chat / Inline / Terminal / Ask / Plan / Agent 概览 | 讲解 |
| 3 | Agent Mode 与工作流升级 | 10 min | Ask → Plan → Agent、local / CLI / cloud、审批与自治 | 讲解 |
| 4 | **Live Demo：Ask → Plan → Agent 闭环** | 15 min | 在 ticket service 中完成一次完整演示 | 讲师演示 |
| 5 | **实验 1：AI-DLC 全生命周期闭环** | 20 min | 用 GHCP Agent 走完 需求理解 → 规划 → 实现 → 测试 → Review → PR 描述 | 分组实操 |
| 6 | **Harness Engineering 讲解** | 10 min | copilot-instructions.md / custom agents / prompt files / MCP | 讲解 |
| 7 | **实验 2：Harness Engineering 实操** | 15 min | 编写 custom instructions 和 custom agent，约束 Agent 行为 | 分组实操 |
| 8 | **Multi-Agent 协作讲解** | 5 min | Mission Control / Coding Agent + Local Agent 协作 / Agent Handoff | 讲解 |
| 9 | **实验 3：Multi-Agent 协作** | 20 min | 多角色 Agent 协作完成"新功能开发 + 安全审查 + 文档生成" | 分组实操 |
| 10 | 落地建议与 Q&A | 10 min | 从 Workshop 到团队试点、收尾讨论 | 讨论 |
